Minimalistic block theme for non-profits and eco-friendly businesses.

== Description ==

Save the Planet is a minimalistic block theme built for the Site Editor. It ships with block patterns for non-profits and eco-friendly businesses, a green and earth-tone color palette, a dark style variation and block templates for WooCommerce.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click Add New.
2. Click Upload Theme and choose the theme zip file, then click Install Now.
3. Click Activate to use the theme on your site.

== Frequently Asked Questions ==

= Does the theme support WooCommerce? =

Yes. The theme includes block templates for product pages, the shop archive, the cart and the checkout.

= Does it use external fonts or scripts? =

No. The theme uses system fonts and loads nothing from external servers.
