# Translations

Save the Planet is translation ready and uses the text domain savetheplanet.

To translate the theme:

1. Create a .pot file with WP-CLI: wp i18n make-pot . languages/savetheplanet.pot
2. Open the .pot file in Poedit and create a .po file for your language.
3. Save the generated .mo file in this folder, for example savetheplanet-de_DE.mo.

You can also translate the theme from translate.wordpress.org once it is published on WordPress.org.
