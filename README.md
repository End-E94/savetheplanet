# savetheplanet
Minimalistic WordPress theme best suited for non-profits and eco-friendly businesses

## Description

Save the Planet is a minimalistic block theme (full site editing) for non-profits and eco-friendly businesses. It includes block patterns, a dark style variation and WooCommerce block templates.

## Requirements

- WordPress 6.6 or newer
- PHP 7.4 or newer
- WooCommerce (optional) for the shop templates

## Installation

1. Download the theme and upload it under Appearance > Themes > Add New.
2. Activate the theme.
3. Open the Site Editor to customise templates, patterns and styles.

## Supported features

- Block theme with theme.json, templates, template parts and patterns
- WooCommerce block templates (shop, product, cart, checkout)
- Dark style variation
- No external fonts, scripts or styles

## Development

Run composer install, then composer lint to check the code against the WordPress coding standards and composer fix to fix what can be fixed automatically.
